RESONATE Tarot Explorer — Standalone Proof of Concept

What this is
- A browser-ready, dependency-free web app.
- No Node, React, Vite, package install, server or cloud container is required to inspect it.
- Open index.html directly in a modern browser, or upload the folder to any static web host.

Included features
- Five cards only: The Fool, The Magician, The High Priestess, The Empress, The Emperor.
- Search across names, symbols, elements, astrology, meanings and keywords.
- Element filters: All / Air / Water / Earth / Fire.
- Card detail view.
- Upright / Reversed meaning toggle.
- Numerology, astrology, element, Jungian / psychological interpretation.
- Spiritual interpretation and visual symbolism.
- Journal prompt and reflection field.
- Connections between cards.
- Bookmark toggle and Previous / Next navigation.
- Reflections and bookmarks are stored only in the current browser using localStorage.

Brand direction
- RESONATE dark editorial / Whisper-inspired visual language.
- Warm muted gold, charcoal surfaces, soft borders, serif editorial headings.
- Responsive from phone through desktop.

Files
- index.html
- styles.css
- data.js
- app.js

No external libraries or APIs are used.
