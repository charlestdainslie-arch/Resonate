# RESONATE 0.9.1 Reading Stage — UAT

Approved flow implemented on this branch:

1. Enter Tarot Reading.
2. Press a 1, 3, or 7 card spread box.
3. The spread box immediately opens a dedicated reading table.
4. Face-down cards are already placed in the selected spread with position labels.
5. `Shuffle Cards` performs a poker-style face-down shuffle and randomises the deck.
6. `Draw Cards` is the gold primary action.
7. Drawing uses the existing reveal / flip / settle animation and existing reading interpretation.
8. `Back to spreads` returns exactly one level.

The landing page was intentionally not changed in this increment.
